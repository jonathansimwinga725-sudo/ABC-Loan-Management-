# ABC Design System

ABC Loan Management uses the supplied ABC identity as the primary product brand. EJ Businesses appears as the platform owner/copyright identity for now.

## Visual direction

- Deep navy: primary navigation, headers and premium financial surfaces
- Bright growth green: primary actions, success states and growth indicators
- White/off-white: content surfaces and readability
- Gold: use sparingly for monetary/value highlights, never as the main action colour
- Blue: secondary information and data visualisation
- Red/amber: risk, arrears and warning states only

## Experience principles

The interface should feel alive without becoming distracting: responsive cards, useful micro-interactions, smooth state transitions, live status indicators, clear charts and immediate feedback. Motion must respect reduced-motion preferences.

Financial information always wins over decoration. Overdue balances, payment status, approval state and ledger-impacting actions must be unmistakable.
